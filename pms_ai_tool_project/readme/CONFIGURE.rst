In *AI > AI Tool* set the users allowed to run each ``bookai_tools_*`` tool and,
for the four that change data, tick *Write enabled* once the system parameter
``pms_ai_tool.write_enabled`` is on.

The users do not need access to the Project app: the tools work on the tasks of
*BookAI Tools* only, with the rights of the module. Stages can be moved by hand
(for example to *Rejected*) from the Project app.
