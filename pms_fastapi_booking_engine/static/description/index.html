PMS FastAPI Booking Engine

Public API of the web booking engine, served as its own FastAPI app under /booking-engine/v1. It needs no token: the engine calls it from the browser of the hotel website.

GET /properties/{propertyId}/availability returns what the room selection page shows for a stay: the room types free for every night, the rates (pricelists) with their cancellation policy, one offer per rate and board, and the recommended rooms for the guests searched.

  • Availability counts the rooms free the whole stay, not night by night, and each rate applies the restrictions and limits of its availability plan (closed days, minimum and maximum stay, quota, maximum availability).
  • Prices are what the reservation would bill, taxes included: the room price of each night, the board services per guest and the tourist tax. A night with no price set in the pricelist makes the offer unavailable, instead of selling the product list price.
  • Cancellation comes from the cancellation rule of the pricelist: free until the end of the deadline day in the property time zone, or non refundable when that day has already passed.
  • Content: the photos of a room type are its images for the property (its own ones and the common ones), as public URLs; its size is the smallest one of its rooms there.
  • Recommended is the cheapest way to lodge every guest in the rooms searched, with the least spare capacity.

Request errors (invalid search, missing or malformed parameters, unknown property or route) are RFC 9457 application/problem+json responses.

Configuration

  1. Create a direct, on-line sale channel for the booking engine and add the pricelists the engine sells to it.
  2. On each property to sell online, open the Booking Engine tab and set that sale channel. A property without it answers 404.
  3. Upload the photos in the Images tab of each room type, for one property or for all of them, and set the size of the rooms.
  4. Uncheck Recommend Rooms in the Booking Engine to hide the recommended rooms of a property.

The module creates the PMS Booking Engine API endpoint, run by the PMS Booking Engine user. Its documentation is at /booking-engine/v1/docs.

Usage

Search a stay of two nights for two adults in one room:

GET /booking-engine/v1/properties/1/availability?checkIn=2026-11-03&checkOut=2026-11-05&adults=2&children=0&rooms=1

checkOut is exclusive: the last night is the day before. Every parameter is required.

Each offer is priced for one unit filled with the guests searched up to its capacity, adults first. The recommended rooms are priced with the guests of each room. availableUnits is shared by all the offers of a room type.
