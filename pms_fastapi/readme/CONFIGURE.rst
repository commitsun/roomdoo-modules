* Go to  FastAPI > FastAPI endpoints  and create a new one with the data:
    * Name: PMS API
    * App: PMS API
    * Root path: /pmsApi
    * User: PMS Fastapi
* After the creation push the sync registry button and restart the Odoo server.
* In the property form, tab Settings, the Online check-in group chooses
  which guest fields the online check-in asks: the gender, the birthdate
  and the identity document (type, number and issuing country). Only the
  identity document is asked by default. The check-in localization decides
  which guests each option applies to.
