Set three system parameters (Settings > Technical > Parameters > System
Parameters):

* ``roomdoo_host_link.host_url``: base URL of the host Odoo.
* ``roomdoo_host_link.secret``: the secret host keeps for this instance.
* ``roomdoo_host_link.instance``: the code of this instance in host.

Without all three, the module does nothing, so it can be installed anywhere.
