#. An administrator creates the card password in the *Payment cards* tab of
   the property, with the *Card password* button. The same button changes it
   or, if it was forgotten, resets it: a reset deletes the cards added in
   Roomdoo for that property.
#. Give the users the *View payment cards* and *Add and delete payment cards*
   groups. Editing a card needs both.
#. Cards added in Roomdoo are deleted a number of days after the check-out,
   set in the same tab.
#. *Configuration > Payment card access log* lists every access.
