#. Create the card password of the property first (see *PMS Payment Card*).
#. In the *Payment cards* tab of the Wubook backend, enter the card password
   of the Wubook account with the *Wubook card password* button and tick
   *Read payment cards*.
#. Resetting the card password of the property removes the Wubook card
   password, which has to be entered again.
