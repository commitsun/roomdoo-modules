PMS AI Tool

Guardrails for the AI tools that Odoo serves over MCP (ai_oca_mcp), and the home of the PMS tools.

A tool is a private method of pms.ai.tools decorated with guarded_tool. Every call:

  • validates its arguments against the declared schema and refuses unknown ones, so no client can send a domain or raw SQL;
  • runs under a statement timeout (15 s by default);
  • for read tools, runs in a read-only transaction that is always rolled back: an accidental write fails and nothing is saved;
  • for write tools, needs two calls. The first one returns a preview and a token signed with the database secret and bound to the user, the tool, the arguments and the data the preview saw; the second one must repeat the same arguments with the token, and it aborts if anything changed or the token expired (10 minutes by default);
  • returns a common envelope with the environment, period, definitions, data quality warnings and generation time;
  • fails with a plain message, never with a traceback.

On top of ai_tool and ai_oca_mcp the module adds:

  • the users allowed to run each tool. Write tools always need an explicit list, and tools/list only shows the tools the key owner may run;
  • a per-tool and a global switch for confirmed changes;
  • MCP annotations (readOnlyHint, destructiveHint);
  • the user, tool and duration of each call in the MCP log, with truncated payloads and a daily purge;
  • immediate revocation: archiving a server, or expiring, changing or deleting a key, cuts access at once instead of waiting for the key cache to expire.

Configuration

System parameters, all optional:

  • pms_ai_tool.environment: label shown in every answer. Defaults to the DOODBA_ENVIRONMENT variable.
  • pms_ai_tool.statement_timeout_ms: statement timeout per call (15000).
  • pms_ai_tool.max_rows: row limit of the listings (50).
  • pms_ai_tool.confirmation_ttl: life of a confirmation token, in seconds (600).
  • pms_ai_tool.write_enabled: True to allow confirmed changes at all. Each write tool must also have Write enabled ticked.
  • pms_ai_tool.log_max_chars: size kept of each request, response and error in the MCP log (4000).
  • pms_ai_tool.log_retention_days: age at which MCP logs are purged (90).

In AI > AI Tool, set the users allowed to run each tool. Create one MCP server per person with the tools they need, and a key for that person with an expiration date.

Usage

Connect Claude Code with the server URL and the personal key, for example:

claude mcp add --transport http odoo https://<host>/mcp/<server key> \
    --header "Authorization: Bearer <personal key>"

To declare a tool:

from odoo.addons.pms_ai_tool.tools import guarded_tool

class PmsAiTools(models.AbstractModel):
    _inherit = "pms.ai.tools"

    @guarded_tool(
        input_schema={
            "date_from": {"type": "string", "format": "date"},
            "date_to": {"type": "string", "format": "date"},
        },
        output_schema={"nights": {"type": "integer"}},
        required_inputs=["date_from", "date_to"],
    )
    def _ai_nights(self, date_from, date_to):
        period = self._ai_check_period(date_from, date_to, 93)
        property_ids = self._ai_scope_property_ids()
        ...
        return {"result": {"nights": nights}, "period": period}

and register it with an ai.tool record of kind generic pointing to pms.ai.tools and the method name.
